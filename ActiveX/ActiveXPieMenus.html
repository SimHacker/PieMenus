ActiveX Pie Menus

By Don Hopkins (xardox@mindspring.com)

I've developed an ActiveX Pie Menu Control, so many people will be able to use pie menus in their own applications and on their web pages. It's designed to be robust and easy to use, and it's free and unpatented, so there are no legal problems with using pie menus however you want.

Please also check out the new JavaScript Pie Menus, which are a lot more up-to-date than this old ActiveX pie menu implementation. There are still a bunch of things the old ActiveX pie menus do (like shaping their own windows), that the new JavaScript pie menu's don't do yet.
