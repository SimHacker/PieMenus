Documentation for Unity3D Pie Menu component.
By Don Hopkins, Stupid Fun Club.

The pie menus are configured with JSON, read from the file "Content/Config/PieMenu.json".
They can also be configured programatically, but it's easier to configure them with JSON.

The file PieMenu.json should contain a dictionary, whose top level keys configure static class variables of the PieMenu class, common to all pie menus.
The dictionary also contains a key "pieMenus" which is a dictionary mapping pie menu id strings to pie menu configuration dictionaries.
Each pie menu configuration dictionary has a key "items" which contains an array of dictionaries that configure each of its items.

Here are the various types of JSON objects that you can specify, and how they are converted to Unity3D objects:

Colors are a comma separted list of 3 (RGB) or 4 (RGBA) numbers from 0 to 1.
Fonts are a string name of a font in the Assets/Resources directory.
Textures are a string name of a texture in the Assets/Resources directory.
Booleans are a string "true" or "false", or a string "yes" or "no", or a boolean true or false value, or a number 0 or 1.
GameObjects are the string name of a game object in the world.
Curves are a string with a semicolon separated list of comma separated pairs of numbers, the keyframe x and y values.
GuiSkins are the string name of a GuiSkin in the Assets/Resources directory.
SubMenus are the string id of a pie menu to use as a submenu.

Callback events:

There are both global class callback events (for receiving
notification from all pie menus) and local object callback events (for
receiving notification from particular pie menus).

Here are the signatures of the callbacks, both global and local:

    public delegate void PieMenuStartHandler(PieMenu pieMenu);
    public delegate void PieMenuEndHandler(PieMenu pieMenu);
    public delegate void PieMenuCancelHandler(PieMenu pieMenu);
    public delegate void PieMenuPinHandler(PieMenu pieMenu);
    public delegate void PieMenuSubMenuHandler(PieMenu pieMenu, PieMenuItem currentItem, PieMenu subMenu);
    public delegate void PieMenuChangeHandler(PieMenu pieMenu, PieMenuItem currentItem, float direction, float distance);
    public delegate void PieMenuUpdateHandler(PieMenu pieMenu, PieMenuItem currentItem, float direction, float distance);
    public delegate void PieMenuUpdateCenterGameObjectHandler(PieMenu pieMenu, PieMenuItem currentItem, GameObject gameObject);
    public delegate void PieMenuUpdateItemGameObjectHandler(PieMenu pieMenu, PieMenuItem currentItem, GameObject gameObject);
    public delegate void PieMenuSelectHandler(PieMenu pieMenu, PieMenuItem currentItem, float direction, float distance);

Here are the global callblack events:

    public static event PieMenuStartHandler onGlobalStartEvent;
    public static event PieMenuEndHandler onGlobalEndEvent;
    public static event PieMenuCancelHandler onGlobalCancelEvent;
    public static event PieMenuPinHandler onGlobalPinEvent;
    public static event PieMenuSubMenuHandler onGlobalSubMenuEvent;
    public static event PieMenuChangeHandler onGlobalChangeEvent;
    public static event PieMenuUpdateHandler onGlobalUpdateEvent;
    public static event PieMenuUpdateCenterGameObjectHandler onGlobalUpdateCenterGameObjectEvent;
    public static event PieMenuUpdateItemGameObjectHandler onGlobalUpdateItemGameObjectEvent;
    public static event PieMenuSelectHandler onGlobalSelectEvent;

Here are the local callback events:

    public event PieMenuStartHandler onStartEvent;
    public event PieMenuEndHandler onEndEvent;
    public event PieMenuCancelHandler onCancelEvent;
    public event PieMenuPinHandler onPinEvent;
    public event PieMenuSubMenuHandler onSubMenuEvent;
    public event PieMenuChangeHandler onChangeEvent;
    public event PieMenuUpdateHandler onUpdateEvent;
    public event PieMenuUpdateCenterGameObjectHandler onUpdateCenterGameObjectEvent;
    public event PieMenuUpdateItemGameObjectHandler onUpdateItemGameObjectEvent;
    public event PieMenuSelectHandler onSelectEvent;
