Feng-Gui Feng-Gui: The Feng-Shui of User Interface Design.

User interface design applies at many levels. Feng Shui is a form of user interface design, that can be applied to many aspects of life. Designing a language for programmers. The syntax and semantics of the language should be rich and expressive, yet streamlined and efficient. Designing a library for application programmers. API, Application Programmer Interface, is a user interface for application developers. Simple, independent, reliable, easy-to-understand APIs. Architecture. Landscaping. Building, furnishing and decorating a house. City planning. Channeling the flow of energy. Graphical user interface's language of pixels and mouse clicks.
