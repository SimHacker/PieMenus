NeWS isn't just a window system. It's a multitasking object oriented
graphical programming environment, like SmallTalk. 

NeWS uses much less bandwidth than X. You can run a NeWS client over a
modem, and still get good interactive performance. This is because
NeWS clients can download code to handle interaction and feedback, and
they can define their own communications protocol, that makes the best
use of the bandwidth.

There are bugs in NeWS.
There is a lot very useful code in NeWS. 
Conix, arbitrarily shaped windows, multitasking PostScript interpreter.
Stuff that people would be free to incorperate into the Gnu window
system. 

Gnu needs a PostScript interpreter.
GnuScript is good, but parts of it are slow. 
NeWS has a fast graphics library, with fantastic curves. 
It uses Vaughan Pratt's fast conic spline package, and it decomposes
arcs and bezier curves into a few conic sections, instead of many
short straight lines. 

NeWS has arbitrarily shaped windows. 
All that code is in there.
